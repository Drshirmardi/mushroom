# داده‌های کاتالوگ خدمات

ساخت کاتالوگ از فهرست services.catalog.json و متن منابع در markdown/ استفاده می‌کند.

اصل PDF و Word، تصاویر OCR، فایل‌های بازبینی، فهرست منشأ منابع (catalog.json)
و راهنمای واردسازی در شاخهٔ codex/raw-data-archive زیر مسیر raw-data/ قرار دارند.
پوشه‌های originals/، review/ و inbox/ برای حفظ ساختار آرشیو نگه‌داری شده‌اند.

برای دیدن آرشیو در پوشه‌ای جدا:

    git worktree add ../mushroom-raw-data codex/raw-data-archive
