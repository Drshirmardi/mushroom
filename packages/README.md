# پوشه packages — کتابخانه‌های اشتراکی (آینده)

این پوشه برای بسته‌های مشترک بین اپلیکیشن‌ها رزرو شده است. در حال حاضر خالی است.

## پکیج‌های پیشنهادی برای آینده (وقتی نیاز واقعی ایجاد شد)

| پکیج | کاربرد |
|---|---|
| `packages/ui` | کامپوننت‌های React مشترک بین اپ‌ها |
| `packages/contracts` | انواع TypeScript و قراردادهای API مشترک |
| `packages/typescript-config` | tsconfig مشترک |
| `packages/eslint-config` | پیکربندی ESLint مشترک |
| `packages/utils` | توابع کمکی عمومی (مثل `cn`, فرمت اعداد فارسی) |

> نکته: فقط وقتی کدی **واقعاً** بین حداقل دو اپ تکرار شد، به اینجا منتقل شود. ساختن پکیج خالی از الان فقط پیچیدگی اضافه می‌کند.
