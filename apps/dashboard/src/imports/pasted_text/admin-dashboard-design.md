Design a premium desktop Admin Dashboard for an Acupuncture Clinic Management System.

The dashboard is designed exclusively for the doctor (administrator), who manages appointments, patients, online consultations, prescriptions, assessments, products, orders, and clinic revenue.

IMPORTANT LOCALIZATION

This platform is built specifically for Iranian users.

- Every visible UI text must be written in professional Persian.
- The entire interface must use RTL layout.
- Use a modern Persian typeface similar to Yekan Bakh.
- Use Persian numerals where appropriate.
- Follow Iranian healthcare and e-commerce UX patterns.
- Do NOT create a translated western dashboard.
- The interface should feel native for Persian-speaking users.

GENERAL DESIGN STYLE

- Premium Healthcare SaaS
- Modern Clinic Management System
- Clean, elegant and minimal
- Calm medical color palette
- White backgrounds
- Deep green primary color
- Soft sage green accents
- Rounded cards
- Subtle shadows
- Spacious layout
- Excellent information hierarchy
- Optimized for 1440–1920 desktop screens
- Sticky header
- Professional RTL sidebar

The design should feel comparable to modern healthcare platforms such as Epic, Practo, Doctolib, or high-end medical SaaS products, while remaining fully optimized for Iranian users.

UX Requirements
--------------------------------------

The interface must prioritize the doctor's daily workflow.

The doctor should be able to perform the most common tasks within one or two clicks.

Important information should always be visible.

Use dashboards, timelines, statistics cards, calendars, tables, and charts instead of long forms.

Maintain a premium medical experience throughout the interface.

The final result should look like a complete enterprise-grade Clinic Management System designed specifically for Iranian acupuncture specialists.
