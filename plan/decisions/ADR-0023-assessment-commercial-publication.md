# ADR-0023 — Configurable assessment commercial publication

- Status: ACCEPTED under continuous owner implementation and explicit configurable-price/PRE_START/no-refund decisions,2026-10-17.
- Phase/task: Phase12/F12-PJ-O03. Supersedes none.

Existing O01 immutable drafts deliberately prohibit publication; changing their status contract would silently activate incomplete configuration. O02 separately establishes exact professional review. The owner requires configurable individual/couples tariffs, payment before starting, no ordinary cancellation/refund and stored owned results. Clinical processing, commercial publication and purchase/entitlement must preserve distinct evidence and lifecycles.

Add one retained commercial publication aggregate referencing exact immutable draft/protocol/owner-controlled terms and fixed versioned owner decisions. New price means new draft/publication; replacement atomically retires prior tariff without rewriting it. Current commercial usability is an internal composable prerequisite, not financial entitlement. Ordinary administrator manages prices and commercial release, never medical approval. Actual legal terms/retention decisions are supplied via existing environment/hash-bound policy release CLI with a new explicit purpose. No default medical/legal text, fake approval or real permission grant is seeded.

No second assessment editor/payment engine/state table per patient. O01 contract stays frozen, existing free/Store/appointment flows unchanged. Later BillingIntent target purchase integration pins exact publication/tariff and protects every result route, so this configuration task cannot itself charge or expose patient data. Couples checkout remains separately gated by approved participation/joint-result consent/algorithm. Validate retained immutable history, scoped authority, races/idempotency/audit rollback and fresh/legacy/API compatibility before acceptance.
